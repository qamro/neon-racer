# neon-racer


**Neon Racer is a 2D arcade racing game built with Python and Pygame. Dodge incoming traffic, switch between three lanes, collect boost pads, and use nitro boosts to increase your speed. Featuring neon-inspired visuals, smooth movement, dynamic difficulty, collision detection, and a scoring system. How long can you survive?**

# Running

To run the game just:

**Clone the repo** 

then:

**execute these two commands(this for activate the virtual environment and run the game):**
- source venv/venv/bin/activate                                           
- python main.py
